A make.fun entry for "Everyday Wonder, Two Days to Find the Line". The program
(`main.ts`, Node 22, no dependencies) writes a single sentence of everyday
wonder to `/output/entry.txt`: coming home in the dark, your key finds the
lock a second before you do — your hand remembering the door your eyes have
forgotten.

## Run

```sh
node main.ts
# writes /output/entry.txt
```
